### Часть 1: Фундамент и экосистема (Установка и структура)

**Цель:** Настроить рабочее окружение и понять, как устроен проект.

#### 1. Теория: Что такое Angular и чем он отличается от AngularJS
Angular (версии 2+) — это полностью переписанный фреймворк на TypeScript. Если вы слышите «AngularJS», речь идет о старой версии 1.x, которая официально не поддерживается с конца 2021 года . Современный Angular использует компонентную архитектуру и строгую типизацию.

**Ключевое новшество (Standalone):** Раньше каждый компонент нужно было объявлять в специальном модуле (`NgModule`). Сейчас Angular по умолчанию использует **Standalone Components** — самодостаточные компоненты, которые импортируют всё необходимое напрямую . Это упрощает структуру.

#### 2. Практика: Установка и создание проекта
Для работы нужен **Node.js** (LTS версия). Проверьте в терминале: `node -v`.

**Шаг 1: Установка Angular CLI (глобально)**
```bash
npm install -g @angular/cli
```
*Комментарий: CLI (Command Line Interface) — главный инструмент Angular-разработчика. Он создает файлы, запускает сервер и собирает проект.* 

**Шаг 2: Создание проекта**
```bash
ng new my-first-app
```
При создании CLI задаст вопросы:
- **Would you like to add Angular routing?** (Выберите `Yes` или `No` — для учебы можно `No`).
- **Which stylesheet format?** (Выберите `CSS`).
*Комментарий: CLI автоматически установит все пакеты и создаст структуру папок.* 

**Шаг 3: Запуск**
```bash
cd my-first-app
ng serve --open
```
*Комментарий: Флаг `--open` автоматически откроет браузер на `http://localhost:4200`. Сервер будет перезагружаться при изменении файлов.* 

#### 3. Разбор структуры проекта (Что где лежит)
Откройте проект в VS Code. Нас интересует папка `src/`:
- **`index.html`**: Главная HTML-страница. Внутри есть тег `<app-root></app-root>` — это «дырка», куда Angular вставляет ваше приложение .
- **`main.ts`**: Точка входа. Запускает приложение (`bootstrapApplication`).
- **`app/`**: Папка с вашим кодом.
    - `app.component.ts`: Корневой компонент (логика).
    - `app.component.html`: Шаблон (вид).
    - `app.component.css`: Стили только для этого компонента.

**Мини-задача (День 1):**
Откройте `src/app/app.component.html`, удалите всё содержимое и напишите:
```html
<h1>Привет, Angular!</h1>
<p>Меня зовут [Ваше Имя]</p>
```
Сохраните файл. Вы увидите изменения в браузере.

### Часть 2: TypeScript и Компоненты

**Цель:** Понять типизацию и создать свой компонент.

#### 1. Теория: TypeScript за 15 минут
Angular написан на TypeScript (TS). TS — это JavaScript с типами.
**Интерфейсы (`interface`):** Описывают «форму» объекта. Это как чертеж.
*Пример:* `interface User { name: string; age: number; }`
Если вы попытаетесь передать в объект `User` строку вместо числа в `age`, TS подсветит ошибку еще до запуска кода .

**Зачем это в Angular?** Когда вы получаете данные с сервера или передаете их в компонент, интерфейсы гарантируют, что вы не перепутаете поля.

#### 2. Практика: Создание компонента «Карточка товара»
По плану мы должны сделать карточку с названием и ценой.

**Шаг 1: Генерация компонента**
В терминале (в папке проекта) выполните:
```bash
ng generate component product-card
```
*Комментарий: CLI создаст папку `product-card` с четырьмя файлами. По умолчанию он создает Standalone-компонент (в декораторе будет `standalone: true`).* 

**Шаг 2: Написание кода (Файлы с комментариями)**

**1. `product-card.ts` (Логика и данные)**
```typescript
import { Component } from '@angular/core';

// Интерфейс описывает, какие данные мы ожидаем в товаре.
// Это помогает избежать опечаток (например, если напишем "prise" вместо "price").
interface Product {
  name: string;
  price: number;
  description?: string; // Знак "?" означает, что поле необязательное
}

@Component({
  selector: 'app-product-card', // Тег, который мы будем использовать в HTML
  standalone: true,             // Современный стандарт: не нужен NgModule
  imports: [],                  // Сюда импортируются другие компоненты/директивы (пока пусто)
  templateUrl: './product-card.component.html',
  styleUrl: './product-card.component.css'
})
export class ProductCardComponent {
  // Создаем объект товара, который соответствует интерфейсу Product
  product: Product = {
    name: 'Ноутбук',
    price: 75000,
    description: 'Мощный и легкий'
  };

  // Метод для демонстрации (пока просто возвращает строку)
  getProductInfo(): string {
    return `${this.product.name} стоит ${this.product.price} руб.`;
  }
}
```

**2. `product-card.html` (Шаблон)**
```html
<div class="card">
  <!-- Интерполяция {{ }} выводит значение из класса компонента -->
  <h2>{{ product.name }}</h2>
  
  <!-- Выводим цену. Можно использовать валютный пайп (| currency), 
       но для простоты оставим так -->
  <p class="price">Цена: {{ product.price }} ₽</p>
  
  <!-- Условный вывод: если description существует, показываем его -->
  <!-- @if - это современный синтаксис Angular (начиная с v17) -->
  @if (product.description) {
    <p class="desc">{{ product.description }}</p>
  }

  <!-- Вызов метода из класса -->
  <small>{{ getProductInfo() }}</small>
</div>
```

**3. `product-card.css` (Стили)**
```css
.card {
  border: 1px solid #ccc;
  border-radius: 8px;
  padding: 16px;
  margin: 10px;
  max-width: 300px;
  font-family: sans-serif;
  box-shadow: 2px 2px 5px rgba(0,0,0,0.1);
}

.price {
  color: #2e7d32;
  font-weight: bold;
  font-size: 1.2em;
}
```

**Шаг 3: Использование компонента в приложении**
Чтобы увидеть карточку, нужно вставить её в корневой шаблон.
Откройте `src/app/app.component.ts` и добавьте импорт:
```typescript
import { Component } from '@angular/core';
import { ProductCardComponent } from './product-card/product-card'; // Импорт

@Component({
  selector: 'app-root',
  standalone: true,
  imports: [ProductCardComponent], // Добавляем компонент в imports
  templateUrl: './app.html',
  styleUrl: './app.css'
})
export class App {
  title = 'my-first-app';
}
```

Теперь откройте `src/app/app.component.html` и напишите:
```html
<h1>Мой магазин</h1>
<!-- Используем селектор, который мы задали в @Component -->
<app-product-card></app-product-card>
```

**Результат:** Вы должны увидеть карточку с ноутбуком.

#### 💡 Важные нюансы (Советы на будущее)
1.  **Синтаксис `@if`**: В старых туториалах вы увидите `*ngIf`. В новых версиях Angular (17+) используется блоковый синтаксис `@if`, `@for`. Он работает «из коробки» и не требует импорта `CommonModule` .
2.  **Где хранить интерфейсы?** В реальных проектах интерфейсы выносят в отдельный файл (например, `models/product.model.ts`) и импортируют в компоненты, чтобы не дублировать код.
