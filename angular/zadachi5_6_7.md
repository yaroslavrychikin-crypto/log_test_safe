# Задачи

###  Задача 1: Две страницы и навигация

**Цель:** Отработать `Routes`, `RouterOutlet`, `RouterLink`.

**Условие:**
1. Создайте два Standalone-компонента: `home` и `contacts`.
2. В `app.routes.ts` настройте маршруты:
   - `''` → `HomeComponent`
   - `'contacts'` → `ContactsComponent`
   - `'**'` → редирект на `''`
3. В `app.component.html` добавьте навигацию:
   ```html
   <nav>
     <a routerLink="/">Главная</a>
     <a routerLink="/contacts">Контакты</a>
   </nav>
   <router-outlet></router-outlet>
   ```
4. Не забудьте импортировать `RouterOutlet` и `RouterLink` в `imports` корневого компонента и подключить `provideRouter(routes)` в `main.ts`.

**Критерий готовности:** При клике на ссылки контент под меню меняется, URL обновляется, перезагрузки нет. При вводе несуществующего URL происходит редирект на главную.

###  Задача 2: Страница со списком с локального API

**Цель:** Отработать `HttpClient`, `subscribe`, `@for`, состояния загрузки и ошибки.

**Условие:**
1. Запустите `json-server` с файлом `db.json`, где есть массив `posts` (минимум 3 поста с полями `id`, `title`, `body`).
2. Создайте сервис `post` с методом `getPosts(): Observable<Post[]>`, который делает `http.get<Post[]>('http://localhost:3000/posts')`.
3. Создайте компонент `posts-list`:
   - В `ngOnInit` подпишитесь на `getPosts()`.
   - Заведите `posts: Post[] = []`, `isLoading = true`, `errorMessage = ''`.
   - В `next` присвойте данные и выключите загрузку; в `error` — покажите сообщение.
4. В шаблоне:
   - `@if (isLoading)` → «Загрузка...»
   - `@if (errorMessage)` → текст ошибки
   - `@for (post of posts; track post.id)` → карточки с `title` и `body`
5. Добавьте маршрут `'posts'` и ссылку в навигацию.

**Критерий готовности:** При переходе на `/posts` виден индикатор загрузки, затем список постов. Если остановить `json-server` и обновить страницу — показывается сообщение об ошибке, а не бесконечная загрузка.

### Задача 3: Форма создания поста

**Цель:** Отработать `FormBuilder`, `Validators`, `ReactiveFormsModule`.

**Условие:**
1. Создайте компонент `post-form`.
2. Через `FormBuilder` создайте `FormGroup` с двумя контролами:
   - `title`: обязательный, минимум 3 символа
   - `body`: обязательный, минимум 10 символов
3. В шаблоне:
   - `[formGroup]="postForm"` и `(ngSubmit)="onSubmit()"`
   - `formControlName="title"` и `formControlName="body"`
   - Под каждым полем показывайте ошибки через `@if (title?.invalid && title?.touched)` с разными сообщениями для `required` и `minlength`.
   - Кнопка «Отправить» с `[disabled]="postForm.invalid"`.
4. В `onSubmit()`:
   - Если форма валидна — выведите `this.postForm.value` в консоль и вызовите `this.postForm.reset()`.
   - Если нет — `this.postForm.markAllAsTouched()`.
5. Добавьте маршрут `'create'` и ссылку в навигацию.

**Критерий готовности:** Кнопка неактивна, пока оба поля не заполнены корректно. При касании пустого поля появляется сообщение об ошибке. После отправки форма очищается.

###  Задача 4: Форма + отправка на сервер

**Цель:** Связать Reactive-форму с `HttpClient` (POST-запрос).

**Условие:**
1. Возьмите сервис `post` из Задачи 2 и добавьте метод:
   ```typescript
   addPost(post: { title: string; body: string }): Observable<Post> {
     return this.http.post<Post>('http://localhost:3000/posts', post);
   }
   ```
2. В компоненте `post-form` из Задачи 3 внедрите `PostService` через `inject()`.
3. В `onSubmit()` вместо `console.log` вызовите `addPost(this.postForm.value).subscribe(...)`:
   - В `next` — очистите форму (`reset()`) и выведите сообщение «Пост создан».
   - В `error` — покажите сообщение об ошибке.
4. Добавьте в компонент свойство `successMessage = ''` и выводите его в шаблоне через `@if`.
5. **Проверка:** после отправки формы перейдите на страницу `/posts` — новый пост должен появиться в списке (обновите страницу, если нужно).

**Критерий готовности:** Форма отправляет POST-запрос, `json-server` сохраняет пост в `db.json`, при переходе на список пост отображается. При остановленном сервере показывается ошибка.

### Задача 5: Полный мини-блог со сборкой

**Цель:** Объединить роутинг, HTTP и формы в одно приложение и собрать его.

**Условие:**
1. Соберите всё вместе в одном приложении:
   - **Главная** (`''`) — краткое описание блога.
   - **Посты** (`'posts'`) — список постов с `json-server` (Задача 2).
   - **Создать пост** (`'create'`) — форма с POST-запросом (Задача 4).
2. Добавьте в навигацию все три ссылки. Убедитесь, что `'**'` редиректит на главную.
3. В списке постов добавьте кнопку «Удалить» у каждого поста:
   - В сервисе: `deletePost(id: number): Observable<void>` с `http.delete(...)`.
   - В компоненте: при клике вызовите `deletePost(id).subscribe(() => ...)` и удалите пост из локального массива (или перезагрузите список).
4. **Сборка:** выполните `ng build --configuration production`. Убедитесь, что в папке `dist/` появились файлы, и запустите их локально через `npx http-server dist/my-app/browser` (путь может отличаться). Проверьте, что приложение работает в собранном виде.

**Критерий готовности:** Приложение позволяет просматривать, создавать и удалять посты. Навигация работает без перезагрузки. Продакшен-сборка проходит без ошибок и запускается локально.
